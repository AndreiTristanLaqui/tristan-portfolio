# Tristan Portfolio

A motion-led resume portfolio built with React, TypeScript, Vite, and GSAP.

## Development

```bash
pnpm install
pnpm dev
```

Run `pnpm build` for a production build and `pnpm typecheck` for a standalone TypeScript check.

## Before publishing

Add Tristan's current resume PDF and replace project imagery with real screenshots or short product captures.
